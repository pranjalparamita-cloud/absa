WHAT'S NEW IN v6
================================================================================
1. Google login rebuilt on st.login() (Streamlit's own OIDC client).
   - Before: the app built the URL and relied on an HTML <meta refresh>.
   - Now: the Streamlit server issues a real 302 to Google.
   - Why it matters: Google refuses to render its login screen inside a frame
     and answers with "403 - That's an error / you do not have access to this
     page". That was exactly the page reported. With a server redirect the
     screen is always top-level, so that 403 cannot happen. Verified by
     launching the app and clicking the button in a real browser.
   - Requires the `authlib` package (already in requirements.txt).

2. The redirect URI changed. It is now:
       https://YOUR-APP.streamlit.app/oauth2callback
   NOT the bare app URL any more. This exact string must be registered in
   Google Cloud or you get redirect_uri_mismatch.

3. "Check my Google settings" button on the login screen. It reads back the
   values the app actually received and tests them against Google, so a typo
   is visible instead of producing a blank Google error page.

4. Build stamp. The login card, the sidebar and the My Account header all show
   "build v6 - 09 Nov 2026". If you deploy and still see v5, the files did not
   reach GitHub.

5. Earlier fixes still included:
   - Blank sunburst chart (branchvalues + fake root node) — fixed.
   - Empty white bars above Edit profile / Change password / admin charts —
     caused by <div> wrappers opened and closed in separate st.markdown calls.
     Replaced with real st.container(key=...) cards.
   - Database path fallback if the filesystem is read-only.
   - requirements.txt range-pinned so any Cloud Python version installs.

DEPLOY — 4 STEPS
================================================================================
1. Unzip. Upload its CONTENTS to the ROOT of your GitHub repo
   (app.py at the top level, not inside a subfolder).

2. Streamlit Cloud -> your app -> Settings -> Main file path:   app.py

3. Streamlit Cloud -> Settings -> Secrets -> paste the [auth] block:
   (see the file "PASTE_INTO_STREAMLIT_SECRETS.txt" in this folder —
    it is pre-filled with your app URL)

4. Reboot app.


GOOGLE CLOUD — THE PART THAT MUST MATCH
================================================================================
In Google Cloud -> APIs & Services -> Credentials -> your OAuth client ID
(Web application) -> Authorized redirect URIs, you need:

    https://nhuepfaebgtaqhk7w86htv.streamlit.app/oauth2callback

Rules:
  - https, exact subdomain, and /oauth2callback on the end
  - no trailing slash after oauth2callback
  - for local testing add:  http://localhost:8501/oauth2callback

AND the account restriction, which is Google's, not the code's:
  Google Auth Platform -> Audience ->
     Testing mode: add the exact Gmail under Test users (max 100, allow 10 min
     for Google to propagate), OR
     click "Publish app". This app asks only for openid / email / profile,
     which are non-sensitive scopes, so publishing needs no Google review.

If you skip that, Google blocks every account that is not a test user. No code
change can bypass it.

TROUBLESHOOTING
================================================================================
"ModuleNotFoundError: No module named 'views'"
    -> FULL package only; the views/ folder is not in the repo. Use QUICKSTART,
       or create views/login.py etc. via GitHub "Add file -> Create new file"
       (typing the slash creates the folder).

"No module named 'streamlit'"
    -> requirements.txt missing or not in the repo root.

"Your app is in the oven" forever
    -> open the build log; it is almost always a dependency install line.

redirect_uri_mismatch
    -> The URI in Google Cloud must equal GOOGLE_REDIRECT_URI / redirect_uri
       EXACTLY, including /oauth2callback.

"Access blocked: app has not completed verification"
    -> Your Gmail is not a Test user. Audience -> Test users -> add it, or
       Publish app.

Google button greyed out / "Google login is off"
    -> No [auth] block in Secrets, or a typo in a key name. Paste the block from
       PASTE_INTO_STREAMLIT_SECRETS.txt and save.

Data resets after the app sleeps
    -> Streamlit Cloud storage is ephemeral; absa.db is rebuilt and the demo
       accounts re-seeded automatically. For permanent users you would move to
       an external database (Supabase/Postgres) — not needed for this project.

Still on "build v5" after deploying
    -> The new files did not reach GitHub. Streamlit only reads the repo, not
       Drive. Check the commit, then Manage app -> Reboot.
