# Deliberately RANGE-pinned, not exact-pinned.
# Streamlit Community Cloud picks the Python version itself (Advanced settings),
# and an exact pin can have no pre-built wheel for that interpreter — pip then
# tries to compile from source and the deploy fails. Ranges let pip choose the
# wheel that matches whatever Python the app runs on.
#
